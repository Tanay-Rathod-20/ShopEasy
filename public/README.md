# Public Assets Directory

This directory contains all client-side static assets served directly to the browser by Express:

- `css/` : Vanilla CSS stylesheets (design tokens, layouts, components, responsive styles).
- `js/`  : Modular vanilla ES6+ JavaScript files (API layer, auth, cart, UI helpers, admin).
- `images/` : Product images and graphic assets.
- `*.html` : Multi-page HTML templates (Home, Product Detail, Cart, Checkout, Orders, Auth, Admin).
